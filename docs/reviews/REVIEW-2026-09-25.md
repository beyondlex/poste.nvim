## Tests added (`344c936`)

22 inline tests in `detectors.rs`, each driving the detector directly
through the tokenizer with a `▮` cursor marker (editor semantics: the
cursor byte belongs to the last token starting at or before it):

- `show_type_keyword`: case-insensitive exact matches, near-misses
  (`table`, `tabless`, `database`), and the 4..=9 byte bound.
- `try_dot_column`: `users.▮` → DotColumn; `FROM db.▮` → SchemaTable;
  the same `db.▮` after WHERE → plain DotColumn (the FROM context is
  what makes it a schema); `db.users.▮` carries both parts; an ident
  not adjacent to a dot is nothing.
- `try_insert_column`: the `(` of INSERT INTO and of COPY; mid-list and
  closing-paren cursors; UPDATE's SET and a VALUES `(` are excluded.
- `try_directive`: `USE` at text start and after `;` (Database), the
  statement after the `;` reset (None), `USER` fused-word rejection.
- `try_show_statement`: TABLES/DATABASES/COLUMNS mapping including a
  type word after `FROM`; CREATE-without-type and plain SELECT give
  nothing.
- `try_grant_revoke`: the object position after ON for GRANT and
  REVOKE; grant keywords and plain SELECT/FROM are not table contexts.
- `try_for_update_of`: the list after OF; FOR UPDATE without OF and an
  identifier spelled `of` after ORDER BY do not match.
- `try_bare_set`: session SET (with and without a value already typed)
  → Keyword; UPDATE's SET and LOCK TABLES → None.

## Recorded, not changed

- **Cursor ON the leading keyword of a detector's target returns None
  in two shapes**: `try_show_statement` with the cursor on `SHOW`
  itself (the backward search starts *before* the keyword, so it never
  re-sees it), and symmetrically `try_for_update_of` with the cursor on
  `of`. Both start working as soon as the cursor reaches the whitespace
  after the word — which is where a completion popup actually asks —
  and the top-level dispatcher has other detectors to answer with. Noted
  so a future "popup disappears exactly on SHOW" report has a home.
- `try_insert_column` reports the bare table name for
  `INSERT INTO schema.table (` — the schema qualifier is dropped from
  the context payload. Column-name completion does not need the schema
  today; recorded in case a consumer ever does.
