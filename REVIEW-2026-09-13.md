## Bugs fixed

1. **`%` in a provider context string killed every statusline redraw**
   (`lua/poste/statusline.lua` `markup`) — the context text returned by a
   provider (poste-db bakes `connection/database` into it, and connection
   names come from user-authored `connections.toml`) was embedded raw into
   the statusline markup. `%` is the statusline escape character: a
   connection named `100%` made every redraw fail with
   `E539: Illegal character` (verified with `nvim_eval_statusline`). The
   text is now `%`-escaped before baking; the highlight group name is
   plugin-controlled and already sanitized. poste-db's legacy inline wiring
   got the matching fix in that repo.
