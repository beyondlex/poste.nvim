## Fixes (each with tests)

- **`redis_executor` flags per-item truncation beside the cells**
  (`items_shape` and the hash arm; contract documented in
  `docs/schema.md`). A list element or hash value past `--max-bytes`
  arrives as its first N bytes with no marker a Lua-side write could
  see — and both sides of a grid edit's verification probe are capped
  by the SAME limit, so probe and cell compared equal and an
  `LSET`/`HSET` built from the cell stored the prefix as the WHOLE
  value, silently cutting the tail. `child_cell` now reports whether the
  child's text was cut, and the shapes carry a parallel
  `item_truncated` / `value_truncated` boolean array (1:1 with the
  cells) — present only when at least one was cut, so today's consumers
  see the same shape as before. Tests cover the cut, clean, and
  never-cut-key (a field NAME is not capped, only values are) shapes.

## Probed, held (recorded on purpose)

- **`context stmt` answers a blank line with the blank itself** — line 2
  of `SELECT 1;\n\n\nSELECT 2;` → (1,1) (0-based), where `stmt-ranges`
  correctly reports no statement there. The Lua consumer is the only
  caller and now defends (its round-52 sibling); changing the binary's
  answer would be a contract change for one consumer. Held.
- **The `context` CLI errors on non-UTF-8 stdin** ("stream did not
  contain valid UTF-8", exit 1). A binary-safe SQL file is exotic; the
  Lua callers `pcall` the run and fall back to the region-blind
  `;`-heuristic, which handles the file. Held.
- **`pg_value_to_json` reads an `i64` under an UNKNOWN column type as a
  JSON number** — a bigint above 2^53 through a column whose type name
  the driver does not report (empty string) loses precision, where the
  INT8/BIGINT-named path stringifies. Every real report names the type;
  held until a report arrives without one.
- `mask_url_password` on `postgres://u:p@ss@h/db` (raw `@` in the
  password), `replace_database_in_url` with `@` in the database name,
  `env::substitute_vars` cycles, `detect_use_statement` with `uſe`
  (ſ uppercases to SS) — all already handled; probes added nothing.
