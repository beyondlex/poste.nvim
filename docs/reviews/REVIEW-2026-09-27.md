## Test added

- **The comment-text contract of `split_statements` is now pinned**
  (`test_split_comment_text_contract`). Probing with `SELECT 1 -- a;b\n;`
  surfaced an asymmetry that no test named: a `--` comment's text is
  dropped from the statement text the binary echoes (the newline
  survives as a separator, which is what keeps `SELECT 1--c\nFROM t`
  from gluing into `SELECT 1FROM t`), while a `/* */` comment survives
  verbatim. Both halves are deliberate — a `;` inside either comment
  still ends nothing — but nothing prevented a refactor from flipping
  either one silently. The contract now has a name.

## Verified clean rather than assumed

- **`split_statements_with`** held on every probe: `'it''s; x'`,
  `$$…;…$$` and `$fn$…;…$fn$` bodies, `$1` placeholders passing through,
  unterminated strings, the MySQL `\'` vs standard-SQL `'C:\'` pair
  (already pinned in `test_split_other_dialects_take_backslash_literally`),
  backtick identifiers, and empty-statement filtering.
- **`env::substitute_vars`** converges on `{{HOST}}` → `{{ENV}}-db` →
  `prod-db`, caps the `{{A}}` ⇄ `{{B}}` cycle at the same 10 rounds the
  Lua copy uses, and leaves `{{}}` (empty name, no match for `[^}]+`)
  untouched. Already pinned; probes confirmed.
- **`parse_json_cell`** only fires on strings starting with `{`/`[`, so
  the text `"null"`/`"123"` stays text. Known accepted trade-off: a TEXT
  column genuinely holding `[1, 2, 3]` arrives on the wire as a JSON
  array, and the Lua grid renders it as a structure. Noted in
  poste-db's round-42 review from the consumer side; keeping the
  SQLite-compatible behavior.
- **`sql_dialect.quote_identifier`** doubles the dialect's own quote
  (`""`, `` `` ``) on all three dialect implementations; the DDL
  generators route every name through it. `alter_column_type` inserts
  the introspected type name raw, which is right for a type and trusted
  (it comes from the server, not the user).
- **`sql_values` bigint guards** send |v| ≥ 2^53 as strings, with the
  boundary conservatively exclusive on the positive side; `float_json`
  keeps `NaN`/`±Infinity` as their engine spellings (pinned by existing
  tests).
- **`display_command`'s C1 wedge**: `char::is_control` reaches U+009F,
  and `format!("\\x{:02x}", c as u32)` collapses the two-byte UTF-8
  encoding of U+0085–U+009F to a single `\xNN` byte — the Lua re-parse
  then yields a different (mojibake) token. A `.redis` buffer cannot
  produce such a key (its escapes are byte-level), so the wedge needs a
  scripted `SET` with an embedded U+0085 to reach; recorded on the
  poste-redis side too.
