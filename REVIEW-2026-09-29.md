## Probed through the real binary, held

- **Binary values, embedded newlines, tabs, emoji round-trip cleanly**
  end to end: `exec-file` emits proper JSON escapes
  (`"line1\nline2"`), and `redis-exec` renders a non-UTF-8 value as
  the hex form (`type: "binary"`, `encoding: "hex"`, byte preview) with
  the empty string and a CRLF-bearing value staying plain strings. A
  >65536-byte string arrives `truncated: true` with `len` = the real
  size — the contract `status_summary`'s len/truncated display leans on.
- **Command failures carry their reason.** A first probe read
  `status: "error"` with a nil-shaped value and looked mute; the raw
  event holds `error: "WRONGTYPE: …"` / the unknown-command text. The
  Lua side keys off that field; no drift.
- **The session loop's Blank contract is now load-bearing.**
  `parse_request` trims the request's `sql` and emits *nothing* for a
  blank — verified live (`{"seq":1,"sql":""}` → no event; the next
  request's seq answered correctly, no desync). poste-db's executor now
  refuses blank statements before dispatch precisely because of this;
  if `parse_request` ever starts acknowledging Blanks, that guard and
  its spec need to know.
- **The SCAN cursor is a JSON string**, pinned by
  `scan_surfaces_cursor_as_list` (`out["cursor"] == "17"`) — the redis
  browser's `new_cursor == "0"` string compare terminates on it.

## Read, held

- `request.rs`: `replace_database_in_url` survives passwords with

## Recorded, not changed

- **`replace_database_in_url` splits at an unencoded `#`/`?` in the
  password** — a `--database` swap would land inside the userinfo. Those
  bytes are not legal there for real URL parsers either, so the swap and
  the connect fail consistently; the unencoded-`/` shape is already
  handled by `mask_url_password`'s credentials-gated widening. Not worth
  a second scanner.
- **The `summary` event carries the raw connection URL.** Audited from
  the Lua side this round: every display and persistence consumer
  redacts (`format.lua`, `sql_log`), so the wire shape stays as-is
  (changing it would be MAJOR per the contract for no visible gain).
